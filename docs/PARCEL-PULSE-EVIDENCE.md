# ParcelPulse

## Problem and audience

Real estate developers and analysts often have to look through multiple sources to compare housing markets. ParcelPulse brings neighborhood data, development trends, and market insights together in one place across 25 U.S. cities.

## Original source

ParcelPulse was developed as a team project for the Google Solutions Challenge at Virginia Tech in Spring 2026.

Project website: https://parcel-pulse-gdg-2026.lovable.app/

Team: Etsub Habtewold, Rijul T, Siddharth Ravi, and Barbaros Zorlu.

## My contribution

## Decision I can explain

The project uses market-relative normalization to compare neighborhoods within each city rather than applying the same thresholds nationwide. This helps account for differences between markets.

## Current limits

The Development Readiness scores have not yet been validated against actual real estate outcomes. Forecasting accuracy also needs further testing using historical data.
